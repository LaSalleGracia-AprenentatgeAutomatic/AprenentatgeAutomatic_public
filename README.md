# Materials del curs

Aquest repositori conté els **materials del curs** (apunts, exemples i enunciats).

---

## 📚 Què trobaràs aquí

- Apunts i material teòric
- Exercicis i exemples
- Enunciats de pràctiques
- Recursos addicionals

La navegació recomanada és sempre a través de la **web**, on el contingut està organitzat per blocs i sessions.

Les pràctiques s’entreguen mitjançant **GitHub Classroom**.  
Els repositoris d’entrega es creen a partir d’aquest material.
